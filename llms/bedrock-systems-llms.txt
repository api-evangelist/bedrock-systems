# BedRock Systems

> BedRock Systems (now operating as BlueRock Security, Inc) is a US-based cybersecurity company building formally verified systems software for critical infrastructure. Its work centers on the NOVA microhypervisor and virtual machine introspection (VMI) tooling, using machine-checked Coq proofs to establish strong security guarantees for virtualization, edge, and embedded platforms. The company does not publish a public web/REST API; its developer surface is open-source systems software on GitHub.

## Open source
- [NOVA Microhypervisor](https://github.com/bedrocksystems/NOVA): Formally-oriented microhypervisor (C++)
- [tenjint](https://github.com/bedrocksystems/tenjint): Python 3 platform for virtual machine introspection (VMI)
- [vml](https://github.com/bedrocksystems/vml): Virtual Machine Libraries (C++)
- [coq-lens](https://github.com/bedrocksystems/coq-lens): Lenses in Coq
